# TCG 데일리 브리핑

포켓몬카드 우선의 TCG 소식을 매일 아침 조사해, 마케터 관점의 브리핑으로 보내 주는 알림이입니다.

- **실행:** Claude Code Routine "TCG 데일리 브리핑" (`trig_01N4CuVVtxvxouvReA2zVvvm`)
- **시간:** 평일(월~금) 09:45 KST에 조사를 시작해 10시 전후 도착, 주말은 쉼 (`CRON_TZ=Asia/Seoul 45 9 * * 1-5`). 월요일은 금요일 이후 소식을 모두 다룹니다.
- **모델:** Sonnet 5.5 고정
- **전달:** Discord 웹후크(메인), 푸시 알림·이메일(백업). Discord 전송이 실패하면 푸시/이메일 첫 줄에 `⚠️ Discord 전송 실패`가 표시됩니다.
- **전송 스크립트:** [`send_discord.py`](send_discord.py) — 표를 목록으로 바꾸고, 2,000자 제한에 맞춰 나누고, 링크 미리보기와 멘션을 끕니다. 루틴 프롬프트에 같은 코드가 들어 있습니다(루틴 세션에는 저장소가 연결되지 않기 때문).
- **웹후크 URL:** 저장소에 넣지 않습니다. 환경변수 `DISCORD_WEBHOOK_URL`이 있으면 그 값을, 없으면 루틴 프롬프트에 넣은 값을 씁니다.
- **지침:** [`BRIEF.md`](BRIEF.md) — 우선순위, 주목도 기준, 출력 형식

## 수정하는 법
- 시간·알림 채널·프롬프트 변경: claude.ai/code → Routines 에서 "TCG 데일리 브리핑"을 편집합니다.
- 관심 키워드나 경쟁사 추가: `BRIEF.md`를 편집하거나 루틴 프롬프트에 직접 추가합니다.
